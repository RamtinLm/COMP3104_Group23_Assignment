COMP3104 is an online DevOps course at George Brown Polytechnic. In this course, I am learning how developers work together on software projects and how to manage code using different tools. We also learn how DevOps helps make software development easier and more organized. I think this course is useful because it teaches us how to work as a team, manage our projects, and understand how software is developed and delivered.


In this course, we learn how to use tools like Git and GitHub to manage our code and work on group projects. We also learn about branches, commits, pull requests, and how to handle merge conflicts. Another topic we study is CI/CD, which helps automate testing and software deployment. I think learning these tools is important because they are commonly used in real software development projects.

By the end of this course, I hope to understand DevOps better and become more comfortable using Git and GitHub. I want to learn how to manage my code, work with other developers, and solve problems when working on group projects. I also want to learn more about CI/CD and how it can make software development faster and easier. I think these skills will be helpful for my future career as a software developer.
